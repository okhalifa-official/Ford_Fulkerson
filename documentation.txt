FORD-FULKERSON ALGORITHM VISUALIZATION - SUMMARY
================================================================================

OVERVIEW
========
Interactive tool for visualizing the Ford-Fulkerson maximum flow algorithm.
Allows users to build flow networks, run the algorithm, and observe augmenting
paths with real-time visual feedback.

Target Users: Students, educators, researchers, algorithm developers


WHAT IT DOES
============
The Ford-Fulkerson algorithm finds the maximum flow in a network by repeatedly
discovering augmenting paths from source to sink and increasing flow along them.

Time Complexity: O(E * max_flow) - O(VE²) with BFS optimization
Key Concept: Bottleneck capacity determines flow increment per iteration


FEATURES
========

Graph Construction:
- Right-click: Add nodes
- Right-click + drag: Create edges with capacity
- S key: Set as source (blue)
- K key: Set as sink (red)
- Delete: Remove nodes/edges
- Drag: Reposition nodes

Controls:
- Play: Run full algorithm
- Step: Single augmentation step
- Speed (+/-): Adjust animation speed (0.25x to 4x)
- Reset: Clear flows, keep graph
- Exit: Quit application

Visual Feedback:
- Edge colors: Gray (no flow) → Red (full capacity)
- Labels: Show current_flow/max_capacity
- Particles: Cyan dots traveling along edges represent flow
- Results: Display maximum flow and all augmenting paths (node sequence)

INSTALLATION
=============
1. pip install pygame numpy
2. Place audio files in project directory
3. python3 main.py

Requirements: Python 3.6+, Pygame, NumPy


HOW TO USE
==========

Basic Workflow:
1. Right-click to add nodes (minimum 2)
2. Select node + press 'S' for source, 'K' for sink
3. Right-click and drag between nodes to add edges
4. Enter capacity value when prompted
5. Click Play or Step to run algorithm

Observe:
- Particles flowing along edges
- Edge colors changing from yellow to red
- Results panel showing maximum flow
- Node paths for each augmentation step


ALGORITHM DETAILS
==================

Process:
1. Initialize all flows to zero
2. Use BFS to find augmenting path (source → sink with available capacity)
3. Calculate bottleneck (minimum residual capacity on path)
4. Increase flow by bottleneck amount
5. Repeat until no more paths exist

Termination: Algorithm stops when no augmenting path exists


LIMITATIONS
===========
- Practical graph size: 100-200 nodes
- Integer capacity assumption
- Requires all audio files present
- Fullscreen mode recommended
- Fixed at 60 FPS display


GLOSSARY
========
Augmenting Path: Path with available capacity from source to sink
Bottleneck: Minimum residual capacity on path
Capacity: Maximum flow limit on edge
Flow: Current amount on edge
Residual Graph: Graph with forward and backward edges
Maximum Flow: Total flow from source to sink


TROUBLESHOOTING
================
Won't start: Check Python 3.6+, install pygame/numpy, verify audio files
No augmenting path found: Set source (S) and sink (K), verify path exists
Nodes overlap: Drag nodes apart
Performance lag: Reduce graph size or decrease animation speed
